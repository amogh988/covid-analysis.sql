 COVID-19 SQL Data Analysis Project

 📌 Project Overview

This project focuses on analyzing COVID-19 data using SQL queries to extract meaningful insights such as total confirmed cases, deaths, recoveries, and trends across different states/countries. The dataset contains daily COVID statistics including confirmed cases, deaths, recoveries, and new cases.

The main objective of this project is to improve SQL querying skills while performing real-world data analysis on pandemic-related data.



 🎯 Objectives

* Analyze total confirmed COVID-19 cases
* Identify states/countries with highest infections
* Track deaths and recovery trends
* Perform data aggregation and filtering using SQL
* Practice advanced SQL concepts using a real dataset



 🛠️ Tools & Technologies Used

* **SQL Server Management Studio (SSMS)**
* **SQL**
* **CSV Dataset**
* **Microsoft Excel** (for basic visualization if used)



 📂 Dataset Information

The dataset includes:

* Report Date
* State/Country Name
* Latitude & Longitude
* Total Confirmed Cases
* Deaths
* Recovered Cases
* New Cases
* New Deaths
* New Recoveries


 📊 SQL Concepts Used

* SELECT Statements
* WHERE Clause
* GROUP BY
* ORDER BY
* Aggregate Functions (`SUM`, `AVG`, `MAX`, `MIN`)
* TOP / LIMIT
* HAVING Clause
* Subqueries
* Data Type Alteration



 🔍 Sample Analysis Performed

1. Find the total number of confirmed COVID cases in each state.

2. Display the top 5 states with the highest confirmed cases.

3. Find the total number of deaths in each state.

4. Show the total recovered cases for every state.

5. Find the state with the maximum number of new cases recorded in a single day.



📈 Key Insights

* Maharashtra recorded one of the highest confirmed cases.
* Recovery rates improved steadily over time.
* Some states showed sudden spikes in daily new cases.
* Death rates varied significantly across regions.
